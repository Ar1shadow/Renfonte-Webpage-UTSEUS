## Version chinoise zoning

La version `utseus-maquettes-zh.html` ne cherche pas a remplir le contenu final. Elle sert a montrer :

- la repartition des zones dans chaque page ;
- les contenus des menus deroulants ;
- la navigation directe vers des pages ou sections ;
- les elements visuels de cooperation Chine-Europe ;
- la signification de la palette rouge / jaune / bleu.

Signification des couleurs :

- Rouge : elements importants, titres, boutons, entrees interactives.
- Jaune : attirer l'attention sur certaines sections ou creer du contraste.
- Bleu : structurer les contenus academiques et renforcer la lisibilite.

## Maquette 1 - Accueil desktop

Objectif : transformer l'ancienne page tres textuelle en une entree claire vers le programme UTSEUS.

Choix IHM :

- Hero avec titre court, proposition de valeur et deux actions principales.
- Chiffres cles visibles des le premier ecran.
- Navigation horizontale classique pour respecter la loi de Jakob.
- Sommaire lateral sticky pour faciliter la consultation d'une page longue.

Justification : cette structure reduit la charge cognitive et aide les publics internationaux a comprendre rapidement le role du programme.

## Maquette 2 - Programmes de mobilite

Objectif : permettre a chaque profil de trouver rapidement les informations qui le concernent.

Choix IHM :

- Segmented control par type de public.
- Cartes programme avec resume court et action "Details".
- Ligne de parcours pour representer les etapes de decision.

Justification : la separation par profil limite le nombre de choix visibles et applique la loi de Hick.

## Maquette 3 - Laboratoire et projets

Objectif : rendre les contenus scientifiques plus lisibles sans les appauvrir.

Choix IHM :

- Axes ComplexCity presentes sous forme de diagramme simple.
- Accordions pour cacher les textes longs.
- Grille de projets avec ouverture d'une fiche detaillee.

Justification : les contenus academiques restent accessibles, mais la page evite l'effet "mur de texte".

## Maquette 4 - Temoignages et ressources

Objectif : renforcer la credibilite et l'utilite pratique du site.

Choix IHM :

- Carousel horizontal de temoignages.
- Bloc ressources pour brochures, guides et contacts.
- Carte de localisation pour contextualiser Shanghai University.

Justification : les temoignages apportent une valeur humaine, tandis que les ressources repondent aux besoins pratiques des etudiants.
