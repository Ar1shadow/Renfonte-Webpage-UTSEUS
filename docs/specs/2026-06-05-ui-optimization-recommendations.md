# UTSEUS UI 界面优化建议

**日期:** 2026-06-05  
**范围:** 桌面端优先；移动端问题暂不纳入本轮重点  
**目标页面:** `/fr/`, `/en/`, `/zh/` 三语长页面  
**定位:** 根据 `rapport 3_UTSEUS.pdf` 与当前 demo，整理后续 UI 设计与实现的优化方向

## 1. 设计目标对齐

本轮 UI 优化应继续围绕报告中的核心目标展开：

- 将页面从“UTC 网站中的一页介绍”转为“UTSEUS 独立门户”。
- 降低文字密度，用图片、卡片、关键数字、图标和信息图承担部分解释功能。
- 保留高校项目的严肃性、可信度和学术感，避免过度娱乐化或营销化。
- 强化中法合作身份：UTSEUS 红、UTC 黄、上海大学蓝三色应有清晰职责。
- 让不同用户能快速找到信息：法国学生、中国学生、教师/行政人员、合作伙伴。

## 2. 品牌与标志

### 2.1 导航栏品牌区

当前已将导航栏左侧替换为 UTSEUS 官方标志，这是正确方向。后续建议：

- 保留完整 UTSEUS 标志作为主品牌识别，而不是自绘圆形 `U`。
- 导航栏 logo 高度控制在 `48-56px` 左右，避免压迫导航内容。
- 若白底导航中 logo 细节过小，可准备一个“横向简化版”logo，只保留图形标志和 `UTSEUS` 英文字样。
- `alt` 文本保持为 `UTSEUS`，不要把中法全称都放进 alt，避免读屏冗长。

### 2.2 Hero 标题

Hero 中的 `UTSEUS` 不应继续使用复古 serif 字体。建议采用两种路线之一：

1. **推荐路线:** 使用接近 UTSEUS 标志的科技感圆角 sans 字体，并让 `T` 使用红色强调。
2. **备选路线:** 直接在 Hero 使用官方 logo 的文字部分，但需要准备透明底、适配深色背景的版本。

Hero 标题应体现工程学院、科技、国际合作，而不是杂志或文学页面气质。

##### 是否可以直接使用原本标志中的字体，将标志中的文字抠出，填充成白色添加进hero

## 3. 字体系统

### 3.1 当前问题

当前标题字体偏 editorial，适合文章封面，但不完全符合“工程、科技、院校门户”的语气。正文使用 sans-serif 是合理的，但中英文/中文混排还需要更稳定的字体策略。

### 3.2 建议字体方案

**品牌/大标题**

- 用于 Hero `UTSEUS`：`Eurostile`, `Bank Gothic`, `Arial Rounded MT Bold`, `Trebuchet MS`, system-ui fallback。
- 目标气质：圆角、几何、科技感、接近 logo。

##### 我并不熟悉这些字体，在首页中你使用这些不同的字体，做一个演示，待我选择之后再删除

**章节标题**

- 建议改为稳重的 sans-serif 或低装饰 serif。
- 可选：`Inter Tight`, `IBM Plex Sans`, `Source Sans 3`。
- 如果保留 serif，只用于少量一级标题，不要覆盖所有 `h1-h6`。

##### 同样在页面中展示不同字体的显示效果，让我进行选择

**正文**

- 法语/英语：`Inter`, `Inter Tight`, system-ui。
- 中文：`Noto Sans SC`, `PingFang SC`, `Microsoft YaHei` fallback。
- 正文行高建议 `1.65-1.8`，段落最大宽度控制在 `68-76ch`。

##### 这是已有的设置，还是待改进的设置？若是已有的设置，我认为当前的行间距和正文字体已较好实现

### 3.3 字距与字号

- 不建议全局使用负字距，尤其会影响中文与法文长标题。
- Hero 大标题可以使用正字距 `0.06em-0.08em`。
- 章节标题字距保持 `0`，以保证三语稳定。
- 正文不宜过小，桌面端建议 `16-18px`。

##### 我并没有概念，你尝试改变某个标题，或者某个段落，形成对比，让我进行选择

## 4. 颜色系统

### 4.1 三色职责

报告中明确提出三色来源：

- **红色 UTSEUS:** 身份、主要行动、重点强调。
- **黄色 UTC:** 动态、提示、局部高亮。
- **蓝色 SHU:** 结构、学术可信度、导航层级。

建议不要让三种颜色平均出现，而是明确分工：

| 颜色 | 建议用途 | 避免用途 |
|---|---|---|
| 红色 | 主按钮、当前状态、Hero `T`、重要链接 | 大面积背景、长段文字 |
| 黄色 | section spine、关键数字标记、提示条、轻量 hover | 正文、主按钮背景 |
| 蓝色 | 标题、导航结构、学术模块背景、footer 深色区域 | 过多按钮竞争 |
| 中性灰白 | 页面背景、卡片背景、分隔线 | 不能过灰导致低对比 |

##### 颜色选择的部分，我认为只用红黄蓝三种颜色可能并不美观，你提出一种相对更加美观的方案，比如可以使用渐变色，或者使用互补色等方案，并不需要将这三种颜色固定太死。当时选择这三种颜色，只是为了体现三个组织的特性，你帮我想几个配色和页面颜色新方案，并且可以制作色卡，展示字体和页面颜色

### 4.2 对比与可读性

- Hero 背景图较暗时，标题和标语必须保持足够亮度。
- 红色按钮在深色背景上可用，但在白底 section 中应检查对比度。
- 淡红背景 `accent-soft` 只适合选中态/提示态，不适合大段容器。

##### 这一部分是什么意思，我不理解，重新解释

## 5. 页面结构与排版

### 5.1 当前页面节奏问题

当前多个 section 采用相似结构：

`标题 -> 大图 -> 文字 -> 组件`

这种结构清晰，但连续出现会显得单调，也没有充分体现不同内容类型的差异。

### 5.2 建议结构

**Hero**

- 保留大图背景，但减少“上海城市宣传片”感。
- 主视觉更应强调校园、学生、工程学习、跨文化合作。
- 在 Hero 中加入 2-3 个信息标签，例如：
  - `Formation franco-chinoise`
  - `Mobilité étudiante`
  - `Recherche appliquée`
- CTA 建议至少两个：
  - 主按钮：`Découvrir le programme`
  - 次按钮：`Voir les mobilités` 或 `Télécharger la brochure`

##### 该大图背景你帮我重新设计，可以设计中法合作的背景或者UTC和UTSEUS的建筑设计，或者两校标志。尽量体现两个学校的特点，将其融合进一张图片。按照你的思路重新设计几张新的图片，让我进行选择
##### 只保留一个按钮我认为没有问题，但是按钮的形式我希望能重新设计，当前的按钮太单调了

**À propos**

- 将关键数字前置，作为快速理解入口。
- 文字缩短，避免第一屏后立刻进入长段落。
- 可采用“两栏布局”：左侧一句核心解释，右侧关键数字/事实卡。

##### 可以将数字前置，但是是否可以使用更活泼一点的展现形式，比如通过形状，图标等，单纯的数字并列柑橘太单调。在创建日期中，可以通过箭头表示历史悠久；在学生数中，可以通过饼图展现中法学生的比例（但是目前并不知道学生比例，你可以通过查询信息获得）；专业可以通过剪头指向四个具体的专业名称；项目数量，也可以添加相应的图标或者标志，展现科研风格。总之就是为了让数据展示更有设计感，目前的罗列并不合适。

**Mobilité**

- 不建议只用普通文本加 filter。
- 建议用左右并列结构区分：
  - Étudiants chinois vers France
  - Étudiants français vers Shanghai
- 每类提供“对象、周期、收益、下一步”的固定格式。

##### 当前该部分的内容较为单调，空白部分较多，重新设计卡片格式，可以设计添加背景图片，修改字体，在普通文本区域，你是否可以有其他想法，使页面更有设计感。

**ComplexCity**

- 这是学术复杂内容，不应只靠段落。
- 建议做成“研究轴线图 + 应用领域卡片 + 折叠详情”。
- 视觉上可以使用蓝色作为主结构色，突出研究可信度。

##### 实验室的不同风格，不用段落的形式进行展示，可以设计重叠圆圈，罗列不同的学术风格，

**Projets franco-chinois**

- 保留卡片网格。
- 每张卡片应展示：项目名、研究轴、简短摘要、可点击状态。
- 可以用颜色或图标区分研究领域，但不要让每张卡片都变成强渐变背景。

##### 所有卡片的图片背景需要进行相应的设计，但是目前暂时先保留，作为之后的工作。可以根据项目的内容进行整理分类，制作可选择的菜单格式，类似Mobilité根据学生类型进行选择的格式
**Témoignages**

- 应从“普通 carousel”转为“学生声音”模块。
- 卡片重点：头像/姓名/身份/项目方向/一句 quote。
- 中法学生可以通过小标签区分，呼应用户群体。

##### 该部分的内容仍然有点单调，重新设计卡片形式，使该部分更有设计感，待收集完用户反馈之后，再确定是否需要小标签区分等细节内容。


**Contact + Ressources**

- 联系人、官方链接、下载资料应分组，不要混在长文本末尾。
- 建议三栏：
  - Contacts institutionnels
  - Documents utiles
  - Liens officiels

##### 该部分还要添加相关联系人的邮箱姓名等联系方式，设计卡片，展示联系人的相关信息

## 6. 按钮与交互组件

### 6.1 按钮层级

建议建立统一按钮系统：

| 类型 | 样式 | 用途 |
|---|---|---|
| Primary | 红底白字，轻微阴影 | 主要 CTA，如下载、联系、探索 |
| Secondary | 白底蓝边，蓝色文字 | 次级行为，如查看项目、跳转官方资源 |
| Ghost | 透明背景，红色或蓝色文字 | 低优先级链接 |
| Filter | 胶囊/segmented control | Mobilité、Projets 的筛选 |

##### 暂时先不设计按钮，可以根据页面布局，设计按钮位置和功能链接，然后我再确定是否要设计新按钮

### 6.2 当前按钮问题

- Hero 只有一个 CTA，行为偏弱。
- Program filter 按钮像默认边框按钮，缺少选中态设计。
- 正文链接和按钮视觉差异不够明确。

##### 正文中已有的标签分类按钮同样太简单单调，重新设计按钮形式

### 6.3 建议交互状态

所有按钮和卡片应至少设计：

- default
- hover
- active/selected
- focus-visible
- disabled 或 unavailable

筛选按钮需要明确显示当前选中项，例如红色边框 + 淡红底 + 字重提升。

##### 同意，在标签筛选按钮中，并没有对以选中的标签进行突出，在重新设计按钮后，设计相应的选中标签

## 7. 图片与媒体使用

### 7.1 主图方向

当前 Hero 使用上海天际线，国际感强，但容易重复旧页面“过度聚焦上海”的问题。建议：

- Hero 主图优先使用 campus + students + engineering scene。
- 上海城市可作为背景元素，不应占据全部语义。
- 图片应尽量来自真实 UTSEUS/SHU/UTC 场景，减少 AI 生成图的通用感。

##### 第一节中已经描述过首页图片的设计目标，体现上海法国的融合，上海大学和UTC的融合，可以通过两城地标，学校建筑，学校和项目标志相互融合进一张图片中，重新设计制作该图片。

### 7.2 Section 图片

- 避免所有 section 都用同尺寸横幅图。
- À propos 可用学生/校园图。
- Mobilité 可用地图线条、行程、课堂交流图。
- ComplexCity 可用实验室、城市数据、研究图示。
- Projets 可用项目卡片插画或真实项目图。

##### 根据具体项目的方向进行相对应的设计，同样也可以在卡片中使用与内容对应的图标，但是图标的风格要求统一。

##### 图片和图标的生成暂时先不作为主要任务，优先实现卡片和页面结构的设计

### 7.3 图片风格统一

建议统一处理：

- 轻微冷色调，保持学术感。
- 红/蓝小面积 overlay 呼应品牌。
- 避免过强渐变、过暗遮罩或纯装饰图。

## 8. 导航与页面定位

### 8.1 顶部导航

- 导航栏应服务 UTSEUS，而不是让 UTC 工具栏抢占注意力。
- UTC utility row 可以保留机构可信度，但应视觉降权。
- 当前 Ukraine flag 与 UTSEUS 页面主题无关，报告中也建议移除。

##### UTC的工具栏需要保留，需要根据已有官网的内容进行保留，这需要符合UTC网站的统一格式，根据UTC旧网站的格式进行保留。

### 8.2 侧边目录

侧边 TOC 是当前页面的优点，应保留。建议优化：

- 当前 section 高亮状态更明显。
- 数字编号可保留，强化长页路径感。
- 侧边栏不要做成太重的卡片，避免和内容卡片竞争。

##### 目前该效果基本实现，不需要进行太多的修改，可以设计缩放，将导航栏进行向左隐藏，使页面居中

## 9. 卡片与模块设计

### 9.1 卡片风格

建议保持卡片半径克制，`4-8px` 即可，符合高校/工程页面气质。阴影应轻，不要像 SaaS 营销页。

### 9.2 Key Figures

关键数字应更像“数据摘要”，而不是普通灰色块：

- 数字大而清晰。
- 使用红色数字 + 黄色短线/角标。
- 下方解释文字简短。
- 可增加一行说明来源或语境，例如 `depuis 2005`、`chaque année`。

### 9.3 Project Cards

项目卡片建议：

- 顶部使用研究领域 tag。
- 标题两行内完成。
- 摘要控制在 2-3 行。
- 整张卡片可点击，但需要明显 hover 和 focus 状态。

##### 卡片的设计信息已明确，你可以根据具体内容进行针对性设计

## 10. 页面氛围

整体氛围建议用以下关键词约束：

- institutionnel
- franco-chinois
- technologique
- clair
- international
- étudiant-centrique

避免以下方向：

- 过度营销化的大型 SaaS landing page
- 过度装饰的艺术展览风
- 只展示上海夜景的旅游宣传感
- 大量渐变卡片导致学术可信度下降

##### 同意，但是需要体现出页面的设计，不应该太注重与学术风格，使得页面太过于单调

## 11. 建议优先级

### P0 - 应优先处理

- 使用 UTSEUS 官方标志统一导航栏品牌。
- Hero 标题改为接近标志的科技感字体或直接使用 logo。
- 修正桌面横向溢出，保证页面主内容居中。
- 移除或降权与 UTSEUS 无关的顶部 utility 元素。

### P1 - 下一轮 UI polish

- 建立统一按钮系统。
- 重构 Hero 的 CTA 和信息标签。
- 调整章节排版节奏，避免所有 section 结构重复。
- 优化关键数字卡片和项目卡片。

### P2 - 内容视觉增强

- 为 ComplexCity 设计研究轴线图。
- 为 Mobilité 设计中法双向路径结构。
- 为 Témoignages 加入更强的学生身份标签。
- 替换更多真实图片资源，减少通用生成图。

##### 优先修改字体和颜色排版布局，重新设计卡片，可以预留出图片或图标的位置，图片和图标设计暂时先不完成。

## 12. 验收标准

后续 UI 调整完成后，建议用以下标准检查：

- 首屏 5 秒内能理解：UTSEUS 是什么、属于谁、面向谁。
- 页面视觉中心是 UTSEUS，而不是 UTC 或上海城市。
- 红、黄、蓝三色各有职责，不是随机装饰。
- 每个 section 的布局有差异，但整体仍统一。
- 按钮样式一致，用户能区分主行动、次行动和普通链接。
- 长文本被拆分、卡片化或可折叠，不再形成阅读墙。
- 法语、英语、中文页面的标题和正文都不溢出、不拥挤。
